# Landing Page - TechNova Solutions

Projeto de um site institucional desenvolvido para a empresa fictícia **TechNova Solutions**, aplicando conceitos de HTML5 semântico e CSS3 responsivo.

## 📌 Funcionalidades e Recursos

- **Navegação Fixa:** Menu superior colado com atalhos suaves para cada seção.
- **Layout Responsivo:** Ajuste automático para telas de celulares e tablets.
- **Componentes Estilizados:** Cards com sombra, bordas arredondadas e efeito `:hover`.
